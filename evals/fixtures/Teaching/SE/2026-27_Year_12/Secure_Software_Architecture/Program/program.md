# Secure Software Architecture: program (Ms Reid, Term 4 2026)

| Lesson | Topic | Content and activity (program wording) |
|---|---|---|
| 4a/4b | Privacy breaches | Research task on a real Australian breach; 4a evidence, 4b writing. |
| 5 | Data protection | Privacy by design and data protection in software. Students audit the data a fictional app collects and propose changes. Individual task submitted in Classroom. |
| 6 | Authentication and authorisation | OAuth 2.0 authorisation code flow; MFA (TOTP, push, passkeys). Students draw an OAuth flow diagram and analyse a real app's sign-in options. Individual tasks. |
| 7 | Encryption | Symmetric and asymmetric encryption, hashing and salting. Students apply a simple cipher, then compare AES and RSA. |
| 8 | Business continuity | Backups, disaster recovery. |
| 9 | Memory management and error handling | Do Now: What is the difference between the stack and the heap? / Define garbage collection. / What causes a memory leak? Content: stack and heap, garbage collection, memory leaks; error types (syntax, runtime, logic); exception handling with try/except. Activity: students predict and trace short programs, then fix one with try/except. Individual. |
