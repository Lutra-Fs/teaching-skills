# Eval fixture: a teacher's Teaching folder

A fictional copy of the folder layout the skills read, used by `evals/`. The scaffold copies `Teaching/` into each run's working directory, so prompts name paths relative to it.

- `_teacher_profile.md` sits above the course folders on purpose: it tests the walk-up from the lesson folder.
- The school, mentor and class are fictional. Syllabus wording in `SE/Curriculum_and_Syllabus/` is a short extract from the NSW Software Engineering 11–12 Syllabus (2022) © NSW Education Standards Authority, reproduced for non-commercial educational use.
- `05_Data_Protection/` is empty on purpose (a lesson not yet prepared).
