# Enterprise Computing 11–12

Board Developed Stage 6 course. Use [Enterprise Computing 11–12 (2022)](https://curriculum.nsw.edu.au/learning-areas/tas/enterprise-computing-11-12-2022/overview/course) with its Course Specifications. Course facts below are an 11 August 2026 routing snapshot: recheck the live course page, implementation advice and record of changes for each new cohort or version (see `../curriculum-lock.md`).

## Structure

- Year 11: Interactive Media and the User Experience; Networking Systems and Social Computing; Principles of Cybersecurity.
- Year 12: Data Science; Data Visualisation; Intelligent Systems; Enterprise Project.
- Check each module's indicative time live. Lock the school-based assessment components and weightings and the HSC examination page; task-count examples are examples.

## What good evidence looks like

Enterprise systems, data, users, project management, safe and secure practice, and social, ethical and legal analysis stay visible in the evidence. Do not import Software Engineering content or assessment because both are Stage 6 Computing.

## Continuity artefacts

Research and user evidence; data provenance and schema; system or network representation; interface or prototype; analysis and visualisation; project-management record; security and privacy decisions; Enterprise Project state.

## Runtime checks

Accounts, permissions and devices; file naming, storage and backup; datasets and expected outputs; privacy, cybersecurity and data ethics; authorship and GenAI conditions.
