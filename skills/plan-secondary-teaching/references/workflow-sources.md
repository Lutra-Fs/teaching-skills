# Workflow: official sources and HSC material

Use for finding official syllabus or support resources, version and applicability questions, and analysing HSC papers or marking feedback. Read `curriculum-lock.md`; `hsc-exam-intelligence.md` only for exam material; `stage-and-pathway.md` when the pathway is uncertain.

1. **Pin the question:** exact course, cohort, version and what the answer will be used for. Reuse the lock in `_course_context.md`; if school adoption is unknown, separate the permitted versions from the confirmed one.
2. **Retrieve the smallest official set** following `curriculum-lock.md`. Label each item as requirement, guidance, example or exam evidence, with its date and applicability. A sample program stays an example.
3. **Compare with the target** course and decision: exact wording and codes, implementation dates, specifications. If a source cannot be read reliably, return that field as unresolved and continue with the rest.
4. **HSC analysis** follows the full chain in `hsc-exam-intelligence.md`: specifications, questions, marking guidance, feedback, standards. Frequency weights revision time; the whole syllabus is still taught. School assessment rules come from the school and NESA assessment pages.
5. **Answer the lookup:** the resources, the supported conclusion, provenance and compatibility notes. Record a newly confirmed lock in `_course_context.md` (with the teacher's OK) so later tasks skip this step. Stop at the answer unless a lesson or unit was also asked for.
